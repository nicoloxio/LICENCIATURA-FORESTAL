# Licenciatura Forestal — V5 visual

- 241 preguntas totales.
- 50 preguntas con gráfico, tabla, esquema o fotografía.
- Mínimo de 5 preguntas visuales en cada ramo del temario.
- Se restauró el gráfico oficial Lenga–Araucaria y se incorporó la pregunta oficial de N/ha con su tabla de frecuencias.
- Las preguntas visuales investigadas incluyen explicación conceptual y revisión de cada alternativa.
- Las fotografías botánicas incluyen atribución y enlace a Wikimedia Commons en la Base técnica.
- Filtro lateral **Sólo preguntas visuales**.

## Ejecutar
```powershell
python -m streamlit run app.py
```

Para desplegar en Streamlit Community Cloud, sube `app.py`, `questions.json`, `curriculum.json`, `sources.json`, los reportes, `requirements.txt` y la carpeta `assets/`.
